# 出雲鳥取ドライブ旅程

2026年11月14日〜15日、高知から出雲・鳥取方面をめぐる2日間のドライブ旅行のしおりです。3Dのハンガーラックに14個の目的地が吊るされていて、カードをクリックすると時刻・写真・詳細情報・駐車場へのGoogleマップリンクを含むスライドショーが開きます。スマホでの閲覧を想定しています。

🔗 **ライブデモ**: https://nawamayumi.github.io/izumo-trip-poster/

## 主な機能

- 2日間・14スポットをハンガーラックに吊るした3Dシーン(Three.js + OrbitControls)。DAY1はテラコッタ、DAY2はグリーンで色分け
- カードをクリックすると、そのスポット専用のスライドショー（写真の表紙 → 詳細情報 → 駐車場/お店の場所）が直接開く
- 駐車場（または、のどぐろ丼店のようにお店自体）へのGoogleマップボタンをスライド内に常時表示
- 複数の目的地が同じ駐車場を使う区間は、そのことが分かる注記付き
- 右下の「とてもわかりやすいふつうのまとめはこちら」ボタンから、元になったシンプルな一覧ポスター(DAY1/DAY2)もいつでも見られる

## 使用技術

- [Three.js](https://threejs.org/) r0.160(CDN + importmap、バンドラーなし)
- `EffectComposer` + カスタム `ShaderPass`(エッジワープ・色収差の演出)
- Canvas 2D で動的に描画したカード・スライドのテクスチャ

## ローカルで動かす

```bash
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。
